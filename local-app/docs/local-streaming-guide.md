# Live desktop

Wails memakai API loopback dan RTSP MediaMTX. NVR wajib HEVC/H.265; audio asli. Start sesi mengaktifkan live/recording, Stop menunggu finalisasi MKV.

libVLC ditanam di panel native. Channel awalnya mute; satu boleh bersuara. Buffer live default 0 ms dapat dinaikkan bila tersendat; bukan angka latency total. Desktop ditutup tidak menghentikan recording/upload. [Setup](setup-api.md), [media](media-engine.md).
