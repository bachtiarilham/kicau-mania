# Alur operasional

1. Build/jalankan engine portable memakai akun Windows pemilik credential.
2. Discovery/probe NVR HEVC/H.265, apply interface/channel.
3. Login cloud di desktop bila ingin upload; pairing dan mapping tiket.
4. Mulai sesi: RTSP, metrik dan MKV. Tanpa mapping tetap bisa merekam lokal.
5. Stop, tunggu terminal/READY. Pantau transfer dan metadata terpisah.
6. Retry mempertahankan file/identitas. Desktop ditutup tidak menghentikan worker.
