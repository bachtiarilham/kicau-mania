# Insomnia local-app

Import local-app-testing.json. Default API http://127.0.0.1:8090. Gunakan environment LAN, GET setup/bootstrap untuk nonce, lalu setup/jobs (discover/profiles/probe/apply), poll job dan mulai sesi.

Gunakan NVR nyata HEVC/H.265; ganti template RTSP dan credential sesuai perangkat. Tidak ada sumber pengganti atau mode konversi. Stop, poll terminal, periksa MKV READY. Endpoint file mendukung Range. Pairing/mapping memakai hasil konfirmasi cloud; lihat ../cloud-contract.md. Mode cloud Bearer tetap tersedia untuk operator layanan. Request negatif auth/origin merupakan tes API nyata.
